# Portfolio Pencapaian MPP UiTMCTKKT Sesi 2025/2026

Next.js 15 (App Router) + Tailwind CSS + Lucide React.

## Jalankan
```bash
npm install
npm run dev     # http://localhost:3000
npm run build   # semak sebelum push
```

## Edit kandungan
Semua teks, statistik, pencapaian, legasi dan hashtag ada dalam **`lib/content.ts`**.
Pautan Google Form: tukar `GOOGLE_FORM_URL` di bahagian atas fail itu.

## Galeri
Letak gambar (`.jpg`, `.jpeg`, `.png`, `.webp`) dalam **`public/gallery/`**, kemudian commit & push.
Gambar disusun ikut nama fail (cth. `01-mecfest.jpg`, `02-clubfest.jpg`) dan nama fail dijadikan kapsyen.
Tip: kecilkan gambar telefon kepada lebar ~1600px (≤500KB) supaya laman pantas dibuka melalui WhatsApp.
